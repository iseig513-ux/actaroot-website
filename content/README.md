# Structured public content

Edit only verified visible facts in `sites.json`. Pages, metadata and JSON-LD all compile from these records.

Keep the primary identifiers unchanged:
- Person: `https://msihu.com/#person`
- Organization: `https://actaroot.com/#organization`
- OHWUT Brand: `https://actaroot.com/#brand-ohwut`

Age currently states 13 as requested and must be updated when it changes. Do not publish exact date of birth, school, address, phone, unverified business results or claimed officer filings.

No new page gets indexed unless it exists in `pages`; do not add speculative update URLs to sitemaps.
